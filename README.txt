즉시 적용용 포트폴리오 뼈대
==========================

1. 저장소 루트의 index.html과 style.css를 이 파일로 교체합니다.

2. 현재 프로젝트 자료는 아래 정확한 경로/파일명만 맞추면 자동으로 표시됩니다.

대표 이미지
assets/images/current-project.jpg

컨셉 아트 PDF
assets/docs/current-project-concept.pdf

제작 노트 TXT
assets/text/current-project-note.txt


파일이 아직 없을 때
-----------------
사이트가 깨지지 않고 '준비 중' 플레이스홀더를 표시합니다.

나중에 완성할 때
---------------
코드 수정 없이 위 경로에 파일만 업로드하면 됩니다.

제작 노트는 이 ZIP에 포함된 current-project-note.txt를 수정한 뒤
assets/text/current-project-note.txt로 업로드하세요.

중요
----
TXT/PDF 존재 여부 확인 기능은 GitHub Pages 같은 웹 서버에서 정상 작동합니다.
PC에서 index.html을 단순 더블클릭(file://)해 열면 브라우저 보안 정책 때문에
fetch가 실패할 수 있습니다.

GitHub Pages에 반영된 실제 주소에서 확인하는 것을 권장합니다.
